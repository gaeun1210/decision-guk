# 결정국 — 고민은 접수하고, 결정은 즐겁게!

고민을 접수하면 성향이 다른 장관들이 공개된 규칙으로 의견을 내고 투표해 판결을 내리는 반응형 웹앱(프로토타입)입니다.

## 실행

`index.html`을 브라우저에서 열면 됩니다. 빌드와 서버가 필요 없습니다. 같은 폴더의 `assets/` 이미지를 함께 두세요.
픽셀 글꼴(Galmuri)은 인터넷 연결 시 CDN에서 불러오고, 실패하면 시스템 글꼴로 표시됩니다.

## 판단 규칙 (규칙 기반, AI 미사용 · 같은 입력이면 같은 결과)

국무회의는 4단계입니다: ① 안건 접수 → ② 장관 질문(쇼핑은 구매 심사) → ③ 가장 중요한 기준 → ④ 결재.

**일반 고민** — 장관마다 질문 하나를 맡고, 사용자의 답이 그 장관의 표가 됩니다.

| 장관 | 기준 | 질문 |
|---|---|---|
| 신중주의(토끼) | 후회 없음 | 어느 쪽이 나중에 후회가 가장 적을 것 같나요? |
| 낭만주의(쿼카) | 즐거움 | 솔직히 어느 쪽이 가장 끌리나요? |
| 현실주의(곰) | 비용·시간 | 어느 쪽이 돈과 시간이 가장 덜 드나요? |
| 행동파(병아리) | 실행 쉬움 | 어느 쪽을 지금 바로 시작할 수 있나요? |

- "비슷해요/잘 모르겠어요"는 기권(0표). "가장 중요한 기준" 장관의 표는 1.5표.
- 1위가 동점이면 국무총리가 동점 선택지 중 하나를 다시 묻는 결선을 엽니다. 전원 기권이면 "판단 보류".
- 판세 표시: 만장일치(3명 이상 모두 같은 표) / 압도적 우세(2표 이상 차) / 우세(1표 이상 차) / 근소한 차이.
- 선택지가 0~1개면 「한다 / 안 한다」(또는 「선택지 / 하지 않기」)로 회의합니다. 선택지는 최대 6개, 각 40자, 중복 불가.

**구매 재판(쇼핑)** — 가격·예산(필수, 원 단위 정수 1~100,000,000, 범위 밖·음수·소수·문자는 거부), 비슷한 물건 보유, 사용 시기, 없을 때 불편함으로 장관이 「구매 승인 / 하루 더 생각하기 / 보류」에 투표합니다.

| 장관 | 규칙 |
|---|---|
| 현실주의 | 가격/예산 > 100% → 보류, ≥ 70% → 하루 더, 그 외 승인 |
| 신중주의 | 보유 + 많이 불편하지 않음 → 보류, 보유 → 하루 더, 별로 안 불편 → 하루 더, 그 외 승인 |
| 낭만주의 | 보유 + 별로 안 불편 → 하루 더, 그 외 승인 |
| 행동파 | 이번 주 사용 → 승인, 한 달 안 → 하루 더, 모름 → 보류 |

- 가격이 예산을 넘으면 표결과 관계없이 국무총리 직권 보류.

## 실시간 근거 (판결 과정: 안건 정리 → 근거 수집 → 장관별 검토 → 표결·이견 조정 → 최종 판결문)

| 유형 | 정보 | 출처 | 키 |
|---|---|---|---|
| 나들이·맛집 | 강수확률·기온·미세먼지·자외선·일몰 | Open-Meteo 예보·대기질(모델 예측값) | 없음 |
| 나들이 | 공휴일·연휴 | Nager.Date | 없음 |
| 맛집 | 출발지에서 각 선택지까지 거리 | Kakao Local | `KAKAO_REST_KEY`(Vercel 환경변수) |
| 쇼핑(해외 가격) | 원화 환산 | Frankfurter(유럽중앙은행 기준환율, 영업일 1회 갱신) | 없음 |

**표 조정 규칙(공개)**
- **표를 옮기는 날씨**: 비(강수확률 ≥ 60%)·미세먼지 나쁨(PM10 > 80 또는 PM2.5 > 35)·폭염(최고 ≥ 33℃)·추위(최고 ≤ 5℃, -5℃ 이하는 한파)이고 신중주의가 🌳야외 선택지에 투표했으면 🏠실내 선택지로 표를 옮긴다. 낭만주의는 표를 유지하고 이견을 남기며, 행동파는 대안 준비를 권한다.
- **주의만 주는 날씨**(표는 그대로): 쌀쌀함(최고 6~9℃)·아침저녁 영하권(최저 ≤ 0℃)·더움(최고 30~32℃)·비 올 가능성(강수확률 30~59%). 신중주의가 옷차림·대비를 권하고, 근거 카드에 "🧥 참고"로 표시한다.
- **좋은 날씨**(위에 해당 없음, 강수확률 ≤ 20%, 최고 10~29℃)일 때만 "날씨도 좋아요"라고 말하고, 기권한 낭만주의가 야외 선택지에 투표한다.
- 맛집: 행동파가 기권했거나 가장 가까운 곳보다 1km 이상 먼 곳에 투표했으면 가장 가까운 곳으로 옮긴다. 비 예보가 있으면 신중주의도 500m 이상 먼 곳에서 가장 가까운 곳으로 옮긴다.
- 나들이 날짜가 3일 이상 연휴면 현실주의는 비용·혼잡을 경고하고, 할까 말까 고민에서 기권한 행동파는 「한다」에 투표한다.
- 표가 옮겨지면 판결문에 「조정 전 → 조정 후」와 근거·출처·조회 시각을 남긴다. 조회에 실패하면 그 정보는 반영하지 않고 이유를 표시한다.

**서버 함수(`api/info.js`)**: 입력 검증(지역 30자, 날짜 오늘~15일, 통화 목록), IP당 1분 40회 제한(429), 성공 결과만 캐시(날씨 30분·환율 6시간·공휴일 1일, CDN `s-maxage`), 외부 응답 5초 제한. 외부 API 키는 서버 환경변수에만 있고 브라우저·저장소에는 없습니다. 고민 제목·내용은 외부로 보내지 않고 지역 이름·날짜·선택지 이름만 보냅니다(📌 일상 유형 — 연애·게임 등 — 은 외부로 아무것도 보내지 않음).

## 📮 국민 여론 광장 (공개 여론조사)

로그인한 사용자가 고민·선택지·기간(1시간/하루/3일/7일)을 올리면, 다른 사용자가 투표합니다. 장관 판결 화면의 "국민 여론에도 물어보기"로 바로 올릴 수 있습니다. 보기는 누구나, 글쓰기·투표·신고는 로그인 사용자만 가능합니다.

| 규칙 | DB에서 막는 방법 (`supabase/polls.sql`) |
|---|---|
| 1인 1표 | `poll_votes` 기본키 (poll_id, user_id) |
| 마감 후 투표 불가, 없는 선택지 불가, 숨김 글 투표 불가 | 투표 전 트리거 검사 |
| 작성자·작성 시각·마감 시각 위조 불가 | 해당 칸 INSERT 권한 없음 + 트리거가 `auth.uid()`·서버 시각으로 채움 |
| 남의 글 삭제·수정 불가 | RLS(`auth.uid() = user_id`) + UPDATE 권한 없음 |
| 선택지 2~6개·각 40자·중복 금지, 제목 100자 | CHECK 제약 |
| 도배 방지 | 계정당 24시간 5개 (트리거) |
| 부적절한 글 | 1인 1신고, 자기 글 신고 불가, 신고 3건이면 자동 숨김 |
| 작성자·투표자 비공개 | 테이블 직접 조회는 "내 것"만, 공개 목록은 합계만 돌려주는 읽기 전용 함수 `poll_board()` |

- `poll_board()`는 다른 사람의 표를 세야 하므로 `SECURITY DEFINER` 함수입니다. 보안 점검(Security Advisor)이 경고하지만, 제목·선택지·합계만 돌려주도록 의도한 설계입니다.
- 한계: 욕설·개인정보를 자동으로 걸러 내지는 못하고 신고로 대응합니다. 여러 계정을 만들어 투표하는 것은 막지 못합니다.

## 로그인·저장과 접근 통제

- **로그인(Supabase Auth, 이메일+비밀번호)**: 로그인하면 기록이 서버(PostgreSQL)의 `decisions` 테이블에, 내 캐릭터가 `profiles` 테이블에 저장됩니다. 비로그인은 **체험 모드**로 이 브라우저(localStorage)에만 저장됩니다. 판결 전 진행 중인 회의는 로그인 여부와 관계없이 이 브라우저에만 24시간 임시 저장되고, 판결·로그아웃 시 지워집니다.
- **행 단위 접근 제어(RLS)**: 모든 정책이 `auth.uid() = user_id`일 때만 허용합니다. `decisions`는 SELECT·INSERT·DELETE만, `profiles`는 SELECT·INSERT·UPDATE만 허용하고 `anon`(비로그인)에는 권한이 없습니다. 판결 기록은 수정(UPDATE)할 수 없습니다.
- **최소 권한**: Supabase 기본 권한(TRUNCATE·TRIGGER·REFERENCES)까지 회수한 뒤 필요한 권한만 다시 부여했습니다. 설정 SQL은 `supabase/schema.sql`.
- **입력 검증 이중화**: 제목 100자·내용 1000자·선택지 2~6개·가격/예산 1~100,000,000원·유형 목록을 화면과 DB CHECK 제약 양쪽에서 검사합니다. `user_id`는 화면에서 보내지 않고 DB가 `auth.uid()`로 채웁니다.
- **XSS**: 사용자 입력은 HTML로 렌더링하지 않고 escape 후 글자로만 표시합니다.
- **보안 헤더**: CSP로 스크립트 출처를 자기 사이트와 jsDelivr로 제한하고(인라인 스크립트 없음), 다른 사이트의 iframe 삽입(클릭재킹)을 막습니다.
- **계정 관리**: 비밀번호 재설정(가입 여부를 드러내지 않는 안내), 회원 탈퇴 시 계정·기록 즉시 삭제.
- **키 관리**: 화면 코드에는 공개(publishable) 키만 있습니다. RLS를 우회하는 service_role/secret 키는 사용하지 않습니다.
- **알려진 한계**: RLS는 "남의 기록"을 막지만, 로그인한 사용자가 브라우저 도구로 **자기 기록에** 판결 결과를 직접 꾸며 넣는 것은 막지 못합니다(판결 계산이 브라우저에서 이루어지기 때문, 영향 범위는 본인 기록). JSON 칸(options·opinions)은 크기만 제한합니다. Supabase 무료 프로젝트는 약 1주 동안 사용이 없으면 일시 정지됩니다.
- 일상 선택을 돕는 놀이용 서비스이며 법률·금융·의료 등 전문 판단을 대신하지 않습니다.

## 파일

- `index.html` — 화면 구조와 스타일
- `app.js` — 판결 규칙, 대화형 결재, 로그인·저장, 통계·공유 로직
- `privacy.html` — 개인정보 처리 안내
- `supabase/polls.sql` — 국민 여론 테이블·RLS·트리거·공개 함수
- `supabase/polls_compare.sql` — 장관 판결 vs 국민 여론 비교 값
- `supabase/followup.sql` — 판결 이후 기록(칸 단위 수정 권한)
- `vercel.json` — 보안 헤더(CSP, X-Frame-Options, HSTS 등)
- `supabase/schema.sql` — 테이블·CHECK 제약·RLS 정책·권한 설정
- `api/info.js` — 근거 수집 서버 함수(날씨·공휴일·환율·장소)
- `supabase/evidence.sql` — 판결 근거 저장 칸 추가
- `supabase/delete_account.sql` — 회원 탈퇴 함수(본인 계정만 삭제)
- `assets/court-scene.png` — 법정 배경(국회의사당·단상·관객). 말풍선과 장관 이름표는 화면에서 같은 자리에 겹쳐 그립니다(`layoutScene`)
- `assets/*_desk.png`, `cat_podium.png` — 장관 캐릭터와 책상(투명 배경). 배경(`court-scene.png`)에 합성한 장면 파일입니다
- `assets/people/` — 사용자가 고를 수 있는 사람 캐릭터 10종(설정 > 내 캐릭터 고르기)
- `assets/owls/`, `owl.png` — 서기관 부엉이 포즈
- `assets/owl.png` — 서기관 부엉이(기록실·결과 화면)

🏛️ 결정국 개인정보 처리 안내

결정국은 일상의 사소한 선택을 돕는 학습용·놀이용 웹 서비스입니다. 꼭 필요한 정보만 받고, 본인 외에는 볼 수 없게 관리합니다.

1. 수집하는 정보

구분항목목적
회원가입·로그인이메일, 비밀번호(암호화된 형태로 인증 서버가 보관)본인 확인, 내 기록만 보여 주기
서비스 이용고민 제목·내용·선택지, 판결 결과, 가격·예산(쇼핑 고민일 때), 선택한 캐릭터, 판결 이후 기록(실행 여부·만족도, 선택)결정 기록실·통계 제공
국민 여론(선택)직접 올린 여론조사의 제목·선택지·기간, 내가 한 투표·신고공개 여론조사 운영. 제목·선택지·참여 인원만 공개되고, 선택지별 득표수는 투표한 사람·글쓴이에게(마감 후에는 누구나) 보입니다. 작성자와 투표자는 공개하지 않습니다.
신고(선택)신고한 글, 신고 사유(개인정보·욕설·광고·기타)부적절한 글 숨김. 신고 3건이면 자동 숨김, 운영자가 확인해 숨김 유지·복원하고 조치 내용을 기록합니다.

저장과 조회는 다릅니다

  • 저장(기록): 로그인하지 않은 체험 모드에서는 결정 기록을 서버에 저장하지 않고, 사용 중인 브라우저에만 저장합니다.
  • 조회(실시간 근거): 날씨·공휴일·환율·가게 거리를 확인할 때는 로그인 여부와 관계없이 지역 이름, 날짜, 가게 이름(선택지), 통화만 결정국 서버 함수를 거쳐 Open-Meteo, Nager.Date, Frankfurter, Kakao Local로 보냅니다. 고민 제목·내용, 이메일은 보내지 않으며, 결정국은 이 조회 내용을 따로 저장하지 않습니다(빠른 응답을 위한 몇 시간 이내의 임시 보관과, 호스팅 업체 Vercel의 기본 접속 기록은 예외).
  • 진행 중인 회의(임시 저장): 새로고침해도 이어서 할 수 있도록, 판결 전까지 입력한 내용을 사용 중인 브라우저에만 최대 24시간 임시 저장합니다. 판결이 나거나 로그아웃하면 지워지며, 서버로 보내지 않습니다.
  • 저장하지 못한 판결(임시 보관): 네트워크 오류 등으로 판결을 기록하지 못했을 때, 결과를 잃지 않도록 사용 중인 브라우저에만 보관했다가 저장에 성공하면 지웁니다. 로그아웃하면 지워집니다.
  • 앱으로 설치(홈 화면에 추가)한 경우: 빠르게 열기 위해 화면 파일(그림·글꼴·코드)만 기기에 저장합니다. 로그인 정보·결정 기록·여론·날씨 조회 결과는 이 저장 공간에 넣지 않습니다.
  • 체험 모드 기록은 계정으로 옮겨지지 않습니다. 로그인하면 그다음 판결부터 계정에 저장됩니다.
  • 📌 일상 유형은 외부 조회를 하지 않습니다.

2. 보관과 접근 통제

  • 데이터는 Supabase(PostgreSQL)에 저장되며, 행 단위 접근 제어(RLS)로 로그인한 본인만 자기 기록을 조회·추가·삭제할 수 있습니다.
  • 판결 결과는 수정할 수 없고(실행 여부·만족도 두 칸만 본인이 수정 가능), 언제든 본인이 지울 수 있습니다.
  • 비밀번호는 결정국 화면 코드가 보관하지 않습니다.

3. 보관 기간과 삭제

  • 회원 탈퇴 시 계정, 결정 기록, 캐릭터 설정을 즉시 삭제합니다. (로그인 → 내 계정 → 회원 탈퇴)
  • 기록은 결정 기록실에서 하나씩, 또는 설정에서 한꺼번에 지울 수 있습니다. 실수로 지우지 않도록 삭제 전에 한 번 더 확인합니다(전체 삭제는 '삭제' 입력).

4. 제3자 제공

수집한 정보를 다른 곳에 팔거나 제공하지 않습니다. 단, 서비스 운영을 위해 Supabase(데이터 저장·인증)와 Vercel(웹 호스팅·서버 함수)을 사용하고, 실시간 근거 조회 때 위에 적은 최소 정보만 외부 정보 서비스로 보냅니다.

5. 유의 사항

결정국의 판결은 입력한 답과 공개된 규칙으로 만든 참고 의견이며, 법률·금융·의료 등 전문 판단을 대신하지 않습니다. 민감한 개인정보(주민등록번호, 계좌번호, 건강 정보 등)는 고민 내용에 적지 마세요.

6. 문의와 신고 처리

개인정보 문의, 게시물 삭제 요청, 잘못된 신고(숨김) 복원 요청은 저장소의 GitHub Issues로 남겨 주세요. 운영자가 확인 후 처리하고, 게시물 조치(숨김·복원·삭제)는 운영 기록으로 남깁니다. 게시판 신고는 각 여론조사의 🚩 신고 버튼으로 할 수 있습니다.
